# Student Record Management System

A Python-based Student Record Management System using SQL for storing and managing student information.

## 📌 About the Project

The Student Record Management System is a database-driven application developed using Python and SQL.

The system provides functionality for managing student records, user registration and login, courses, results, and reports through a structured database system.

## 🚀 Features

- User Registration
- User Login
- Student Record Management
- Course Management
- Result Management
- Student Reports
- Dashboard
- SQL Database Integration
- Organized project interface

## 🛠️ Technologies Used

- Python
- SQL
- SQLite
- Python Database Connectivity
